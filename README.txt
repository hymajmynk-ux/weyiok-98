محفظتي — مشروع محاكاة واجهة فقط
=================================

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح.

بيانات الدخول التجريبية:
رقم الهاتف: 01000000000
كود الدخول: 1234

النشر على GitHub Pages:
1) أنشئ مستودع GitHub جديداً.
2) ارفع الملفات الثلاثة: index.html و style.css و app.js.
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root).
4) احفظ وانتظر رابط الموقع.

تنبيه:
هذا مشروع واجهة مستقل للتجربة فقط. لا يتصل بأي بنك أو شركة اتصالات،
ولا ينفذ تحويلات أو مدفوعات حقيقية. جميع الأسماء والأرقام والمعاملات
والأرصدة خيالية، وكل شاشة موسومة بأنها DEMO.
